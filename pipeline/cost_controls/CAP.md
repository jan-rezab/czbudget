# PSD project cost circuit

The website reads a private shared control object every 30 seconds. At 10,000 CZK per Prague calendar month or 2,000 CZK per Prague calendar day it serves a small Czech/English 503 notice, including for cached trade responses. Warnings use the existing Monitoring notification channels at 7,500 CZK/month and 1,500 CZK/day. A stopped period stays stopped; day/month reset only at the corresponding Prague boundary. An enabled monitor older than 30 minutes fails closed.

This is a serving cutoff, not an exact invoice ceiling. Billing export and metrics arrive late; retained storage and unrelated workers remain billable. Gross project-only exported costs are compared with a conservative estimate of EU BigQuery billed bytes, Cloud Build machine execution, Cloud Run CPU/memory/requests/egress, and prorated storage/other-service allowances. Estimates include no free-tier or promotional credit. An empty new export is explicitly pending. Query admission reserves the maximum possible charge atomically before web queries and refunds only verified unused reservation. Cross-instance races cannot individually admit the same remaining balance. Conservative overlapping observations/reservations can stop earlier.

`cap.py` runs only in a bounded Cloud Build control job in europe-west4. It does not ingest data, publish warehouse releases, deploy Cloud Run, cancel unrelated builds, or delete retained objects. Source is immutable under the private `processing-runs/cost-control/` prefix. The dedicated `psd-cost-controller` identity has only metadata/query-job/control-build/log permissions plus access to cost-control state. Financial access is through the exact project-filtered authorized view `psd_cost_control.psd_project_costs`; it receives no raw billing-export or dataset-wide reader grant. Web runtime writes only `static-assets/cost-control/admission/`.

Rollout order: verified website image; validated report release; approved exact controller/admission/view IAM; one successful disabled controller run; recurring 15-minute control job; enable shared config and run once; verify the live pause/status/report contract. Flags remain disabled until these checks pass. Do not describe a prepared or disabled controller as live protection.

Price inputs: Google Cloud CZK catalog effective 2026-09-28, retained in the root task receipt. BigQuery on-demand 129.4275 CZK/TiB; Cloud Run CPU 0.000497001 CZK/CPU-second, memory 0.000051771 CZK/GiB-second, requests 0.000008283 CZK/request; internet egress allowance 2.174382 CZK/GiB. Fixed storage estimate 531 CZK/month, additional services allowance 1,000 CZK/month. These last two are estimates, not exported invoice observations. Cloud Build prices are in `cap-prices.json`, separately by region and machine type. Unknown machine types fail closed. Metadata queries are bounded to 2 GiB; the monthly jobs query scans once and calculates the day conditionally.
