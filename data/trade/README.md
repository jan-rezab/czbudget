# Annual merchandise trade

`annual-hs2-YYYY.v1.json` is generated by:

```bash
npm run fetch:annual-trade
```

The source contract is `pipeline/config/un_comtrade_source.v1.json`. The first
layer is annual UN Comtrade merchandise trade by reporter, import/export flow
and HS two-digit product chapter, with partner fixed to World. Countries are
requested in descending nominal GDP order using the site's existing IMF WEO
series. The compact public artifact contains product values, country totals,
trade balances, coverage states and source lineage.

Raw API responses, reference tables and the resumable run manifest live under
`../data/sources/trade/YYYY-MM-DD/un-comtrade/annual/YYYY/` in the workspace;
they are intentionally outside the deployable website repository. Rerunning the
command reuses valid responses and only spends calls on missing reporter/flow
pairs.

Useful options:

```bash
python3 scripts/import_un_comtrade_annual.py --limit 10
python3 scripts/import_un_comtrade_annual.py --countries USA,CHN,DEU
python3 scripts/import_un_comtrade_annual.py --year 2024 --max-calls 100
```

Set `UN_COMTRADE_API_KEY` to use an authenticated free or premium subscription.
Without it, the importer uses the anonymous preview endpoint; HS2 × one flow ×
one reporter stays below its 500-record response ceiling.
