Public Spending Data API

Source-traceable public finance data with currencies, periods, accounting perimeters, budget stages, and missingness preserved.

Base URLhttps://publicspendingdata.org/api/v1
Authentication

Pass the Identity Platform ID token returned by POST /auth/login as a Bearer token. Refresh it before its one-hour expiry.

curl https://publicspendingdata.org/api/v1/countries/CZE/fiscal \
  -H "Authorization: Bearer $PSD_ID_TOKEN"

Interpretation rules

Native first

National classifications and currencies are not silently coerced.

Missing is not zero

Unavailable and not-applicable values remain explicit.

Perimeters matter

National, local, social-insurance, and corporation layers are not automatically additive.
