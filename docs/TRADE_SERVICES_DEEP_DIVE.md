# Annual services in the trade deep dive

The new `#services` section follows the trade report's country selector and visual language but keeps annual UN Comtrade services (`S/A/EB`) separate from goods, including goods' monthly view. It shows source-reported World exports/imports, their calculated difference, annual history, top-level EBOPS service groups and bilateral partners for the latest reported year. Missing years, flows and countries stay visibly unavailable rather than becoming zero.

`/api/v1/trade/services?country=ISO3` returns exact `source_value_usd` strings beside numerical display values. World totals use `partner_area_code=0` and `product_code=S`. Bilateral partners and parent/child EBOPS groups are not added to those totals. EB10S is preferred to EB02 when both exist for a reporter-year-flow. The source period is limited to 2000–2024; 2025 remains held. Each result names its published snapshot release and observation date when served from a cloud release.

The production API consumes `static-assets/trade-services/current.json` and SHA-verified immutable reporter payloads from a separate data-plane publisher. It must not fall back to a live BigQuery request when snapshots are unavailable. Keep the section unreleased until the annual source checkpoint, raw-to-BigQuery acknowledgments, serving snapshot and public browser behavior are independently verified. Website deployment never runs the data publisher.
